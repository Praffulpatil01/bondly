## Required Ordering

1. SEC-01 through SEC-05 design, security, policy, and billing decisions; no public traffic yet.
2. SEC-03 plus CORE-01 guest/interest experience.
3. SEC-02 then CORE-02/03/04 matching, chat, lifecycle.
4. SEC-04 then CORE-05 report/block integration and operational moderation readiness.
5. UX-01 only against stable, truthful flows.
6. REL-01/02 staging, release gates, and final production approval.

## Approval Boundaries

Before implementation, obtain explicit authorization for production Firestore rule changes, new/changed collection schemas or indexes, Cloud Functions/other backend resources, Firebase billing-plan changes, and production deployments. This document proposes work only; it performs none of it.
